2.¶

For the series in the "hedge fund series" tab, calculate the following statistics related to tail-risk.

  • Skewness
  • Excess Kurtosis (in excess of 3)
  • VaR (.05) - the fifth quantile of historic returns
  • CVaR (.05) - the mean of the returns at or below the fifth quantile
  • Maximum drawdown - include the dates of the max/min/recovery within the max drawdown period.

There is no need to annualize any of these statistics.

In [3]:
skewness = hedge_fund_series.skew()
kurtosis = hedge_fund_series.kurtosis()
var_fifth = hedge_fund_series.quantile(0.05)
cvar_fifth = hedge_fund_series[hedge_fund_series <= var_fifth].mean()
#max drawdown = largest peak to trough 
cum_rets = (1 + hedge_fund_series).cumprod()
rolling_max = cum_rets.cummax()
drawdown = (cum_rets - rolling_max) / rolling_max
mdd = drawdown.min()

min_dates = {}
max_dates = {}
recovery_dates = {}

for col in hedge_fund_series.columns:
    min_date = drawdown[col].idxmin()
    max_date = cum_rets.loc[:min_date, col].idxmax()
    post_min = cum_rets.loc[min_date:, col]
    recovery_date = post_min[post_min >= cum_rets[col].loc[max_date]]
    min_dates[col] = min_date
    max_dates[col] = max_date
    recovery_dates[col] = recovery_date.index[0].date()

tail_summary = pd.DataFrame({

7.¶

Let's examine the replication out-of-sample (OOS).

Starting with $t = 61$ month of the sample, do the following:

  • Use the previous 60 months of data to estimate the regression equation. This gives time-t estimates of the regression parameters, $\tilde{\alpha}^{\text{merr}}_{t}$ and $\tilde{\beta}^{\text{merr}}_{t}$.

  • Use the estimated regression parameters, along with the time-t regressor values, $x^{\text{merr}}_{t}$, calculate the time-t replication value that is, with respect to the regression estimate, built "out-of-sample" (OOS).

$$\hat{r}^{\text{hfri}}_{t} \equiv \tilde{\alpha}^{\text{merr}} + (x_{t}^{\text{merr}})'\tilde{\beta}^{\text{merr}}$$

  • Step forward to $t = 62$, and now use $t = 2$ through $t = 61$ for the estimation. Re-run the steps above, and continue this process throughout the data series. Thus, we are running a rolling, 60-month regression for each point-in-time.

How well does the out-of-sample replication perform with respect to the target?

In [9]:
# Previous variables
# data = [HFRIFWI_ret, merrill_factors]
# HFRIFWI_ret = data["HFRIFWI Index"]

X = data[merrill_factors.columns]

window = 60

oos_replication = pd.Series(index=data.index, dtype=float)

for t in range(window, len(data)):

    y_train = HFRIFWI_ret.iloc[t - window:t]
    X_train = X.iloc[t - window:t]

    X_train = sm.add_constant(X_train)
    model = sm.OLS(y_train, X_train).fit()

    X_test = sm.add_constant(X.iloc[t:t+1], has_constant="add")

    oos_replication.iloc[t] = model.predict(X_test).iloc[0]

# Calculate errors OOS
hfri_oos = HFRIFWI_ret.iloc[window:]
errors = hfri_oos - oos_replication.iloc[window:]

print("Out of Sample Performance\n" + "-"*35)
print(f"R-squared: {1 - (errors**2).sum() / ((hfri_oos - hfri_oos.mean())**2).sum():.4f}")
print(f"Annualized tracking error: {errors.std() * np.sqrt(12):.2%}")
print(f"Annualized RMSE: {np.sqrt((errors**2).mean()) * np.sqrt(12):.2%}\n")

The out-of-sample replication performs well in tracking the HFRI index. The Out of Sample R-squared of 0.81 indicates strong explanatory performance relative to real data. Besides, the annualized tracking error of 2.75% suggests relatively low variability in the differences between actual and replicated returns, while the annualized RMSE of 2.78% indicates a similarly small overall magnitude of replication errors. Overall, the model captures most of the index's return movements, although some deviations remain during periods of heightened market volatility.

def optimized_weights(returns,dropna=True,scale_cov=1):
    if dropna:
        returns = returns.dropna()

    covmat_full = returns.cov()
    covmat_diag = np.diag(np.diag(covmat_full))
    covmat = scale_cov * covmat_full + (1-scale_cov) * covmat_diag

    weights = np.linalg.solve(covmat,returns.mean())
    weights = weights / weights.sum()

    if returns.mean() @ weights < 0:
        weights = -weights

    return pd.DataFrame(weights, index=returns.columns)
